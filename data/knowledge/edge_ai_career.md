# 外部知識: エッジAI/低レイヤ技術者のキャリア要件 (2026年時点の整理)

## エッジAIエンジニアに求められるスキルセット
- モデル量子化 (GGUF/AWQ/GPTQ)、蒸留、プルーニングの実務経験
- ARM NEON / SVE / SME、Hexagon NPU (Snapdragon) 向けカーネル最適化
- llama.cpp / ONNX Runtime / ExecuTorch 等の推論ランタイム内部理解
- メモリ帯域・キャッシュ階層を意識したデータレイアウト設計 (AoSoA等)
- Python (計測・パイプライン) と C++ (コア実装) の両輪

## 市場動向
- オンデバイスAIの需要拡大により「低レイヤ最適化 × ML」の複合人材は希少で高需要。
- 純粋なモデル研究職より、推論基盤・最適化エンジニアの求人倍率が高い。
- 低レイヤの積み上げはエッジAI分野への転用性が極めて高く、キャリア資産として毀損しない。

## スキルギャップの典型
- 低レイヤ出身者に不足しがち: モデル学習側の知識 (LoRA/データセット設計)、
  精度評価の作法 (ベンチマーク設計、劣化検知)。
- ML出身者に不足しがち: プロファイリング、SIMD、メモリレイアウト、ビルド基盤。
