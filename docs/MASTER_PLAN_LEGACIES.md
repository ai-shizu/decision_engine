# MASTER_PLAN_LEGACIES.md — The Final 5 Legacies (Architect's Blank Check)
# 発行: 2026-07-07 / 起草: fable5 (リード・アーキテクト) / 実装: Sonnet5 (後日)
# 位置づけ: 詳細 SPEC ではなく青写真。各 Legacy の着手時に個別 SPEC を錬成すること。

> **選定基準**: 機能の追加ではなく「ループの閉鎖」。現システムは (1) 入力が
> 金と予定に偏り、(2) 実選考結果という唯一のグラウンドトゥルースに未接続で、
> (3) oracle の処方の効果を測らず、(4) 計測器自身の校正装置を持たない。
> 5 遺産はこの 4 穴 + 本番面接が音声であるという事実を塞ぐ。
> 憲法 (完全オフライン / 物理量絶対 / 非対称性 / UI黒箱・ディスク白箱 /
> 第三者隔離) は全遺産に無条件で優先する。

## Legacy 1 — LARYNX (発話物理テレメトリ)

- **Core Mechanism**: whisper.cpp (ARM64 ローカル、llama と同じ tools/ 配置) で
  interview_sim を音声応答化。測定は意味ではなく発話の物理のみ: 初動レイテンシ
  (質問表示→第一声 ms)、ポーズ分布 (>800ms 沈黙の位置・長さ)、フィラー率
  (えー/あの・毎分)、発話速度 (mora/s)、言い直し回数。既存 response_time_sec
  系に合流し、講評フェーズでのみ統合 (既存の非対称構造にそのまま乗る)。
- **Architect's Justification**: 本番面接は音声である。テキストの思考速度と
  発話の思考速度は別の器官であり、現システムは後者を一切測っていない。
  「嘘をつかない物理量」の最大の未開拓鉱脈。
- **Sonnet Handoff Hint**: whisper の stdout は stderr へ退避 (プロトコル純度
  I-2)。VAD 閾値は定数凍結 — 自動調整は非決定論の混入。**音調・ピッチからの
  感情推定は永久禁止** (憲法 2: タイミングと語彙の物理のみ)。生音声はセッション
  終了時に即削除し、テキスト+計測値のみ永続化 (データ最小化 T-10 系)。

## Legacy 2 — SCAVENGER (デジタル排気インテーク)

- **Core Mechanism**: ローカルに既に存在するデジタル排気の決定論パーサ群:
  git log/reflog (lane 20)、LeetCode ローカル履歴 (lane 21)、ブラウザ履歴
  SQLite (ドメインカテゴリ別滞在)、OS ウィンドウフォーカス時間 — PKBTEN01 の
  予約レーン 22-27 へ。importer 共通基底が `coverage() -> (start,end)` を
  必須実装として強制する。
- **Architect's Justification**: 客観チャネルが家計簿+予定に偏っている。
  注意 (attention) は金より嘘をつかない資源台帳であり、「LeetCode をやった」は
  宣言ではなくコミットログが知っている。task_executed (lane 19) の検出精度も
  桁が上がる。
- **Sonnet Handoff Hint**: ロック中 SQLite は**コピーしてから開く**
  (apple_calendar_sync の確立パターン)。coverage 必須化は E1.1 の教訓
  (沈黙=観測済み0 と欠測の区別) を**型シグネチャで強制**するため — 実装忘れを
  構造的に不可能にせよ。ネットワーク I/O を持つ importer はレビューで即落とす。
  カテゴリ語彙は THEME_TAXONOMY の 4 点セット規則 (§6.5) に相乗り。

## Legacy 3 — BLACKBOX (実戦飛行記録と結果台帳)

- **Core Mechanism**: (a) 実面接の直後キャプチャ UI — 忘却の双曲減衰に合わせた
  24h 以内の構造化デブリーフ (受けた質問・自己知覚の詰まり・体感レイテンシ)、
  (b) 選考結果台帳 — 企業×段階×結果の append-only ledger、(c) 実戦校正 —
  twin/講評の予測を実結果とプール Brier で照合し、システム全体の的中率を
  ディスクに正直に記録する。
- **Architect's Justification**: 現システムの評価関数は全て代理変数 (シム成績・
  walk-forward BSS) であり、実選考の合否という唯一のグラウンドトゥルースに
  接続していない。接続した瞬間、本システムは「自己分析ツール」から
  「校正済みの計測器」に変わる — これが 5 遺産の中で最も凶暴な一手である。
- **Sonnet Handoff Hint**: 実面接ログは simulated=False (genuine 記憶) だが
  経過時間フィールド (記憶劣化の定量値) を必ず付与。台帳は HistoricalNode と
  同じ append-only + 訂正リンク — 編集・削除 API を作るな (I-10 系)。選考 n<10
  で校正を語らない (I-20 と同じ確度ゲート)。**面接官個人のプロファイル構築は
  禁止** (憲法 5) — 記録するのは自分の応答と結果のみ。

## Legacy 4 — CHRONOSCOPE (自己差分と介入の会計監査)

- **Core Mechanism**: deep_profile の世代スナップショット (content-hash キー・
  append-only・軸/gap/sig結合のみの安定要約) + 決定論 diff エンジン
  (added/removed/changed の型付き差分) + 介入効果の中断時系列分析 — oracle 介入の
  採否をテンソルのレーン変化で実測し、pre/post 窓の差を E2 遠ラグ帰無の機構を
  **再利用**して有意判定する。
- **Architect's Justification**: oracle は処方するが、処方が効いたかを誰も
  測っていない。結果測定の伴わない自己改善は占星術である。これは unlearning_rate
  軸 (D1) の実装基盤にもなり、Echo の全出力に会計責任を与える。
- **Sonnet Handoff Hint**: スナップショットは全量コピー禁止 (肥大 T-10) —
  スキーマ安定な要約のみ。**効果推定は因果ではなく相関である事実を出力スキーマ
  自体に明記せよ** — n=1 の中断時系列を「証明」と呼んだ瞬間、システムは欺瞞に
  堕ちる。介入採否の判定は物理量 (レーン変化) のみで行い、自己申告を使うな。

## Legacy 5 — PHANTOM (合成ペルソナ校正装置)

- **Core Mechanism**: 種付き決定論 (Philox・I-17) の合成生活ログ生成器 —
  日記/LINE/家計簿/予定を規則ベースで合成し、既知の真実 (planted gap・摩擦
  イベント・真ガクチカ・既知ラグの結合) を埋め込む。パイプライン全段
  (gap → telemetry → tensor → coupling → twin) がその真実を回収することを
  known-answer test として CI で強制する。
- **Architect's Justification**: 「決定論的」を誇るシステムは、既知解での校正を
  自らに課す義務がある。現在のテストは単体レベルで、「システム全体が正しい
  発見をするか」は誰も検証していない。語彙表・閾値の将来の変更が検出力を殺す
  退行を防げるのは、これだけである。**他の 4 遺産より先に着手せよ** —
  校正装置なしに計測器を増築するのは倒錯である。
- **Sonnet Handoff Hint**: 実データディレクトリ接触禁止 (一時 PKB_PROJECT_ROOT、
  I-5)。**fixture-blindness 規律**: 検出語彙 (THEME_TAXONOMY 等) をフィクスチャに
  合わせて調整する変更は校正の自殺 — フィクスチャ生成規則は語彙表から独立に
  書け。合格判定は「完全回収」ではなく回収率の下限 (雑音劣化への余裕) で定義し、
  閾値を 100% に「強化」する提案はテストの意味の破壊として却下せよ。

そして自分の計測器を自分で校正しろ。*
