## F-2 — DoD 節の固定スナップショットを撤去せよ【最優先】

### 事実

`6c05c99` が `docs/AI_SKILLS.md` の DoD 節へこの行を追加した:

```

```

`tests/test_dod_boundary_contract.py::test_ai_skills_dod_has_no_fixed_snapshots` はこれを明示的に禁じている:

```python
assert not re.search(r"\d+\s*passed", dod, flags=re.I)
assert not re.search(r"\d+\s*件", dod)
assert not re.search(r"\d+\s*modules?", dod, flags=re.I)
assert not re.search(r"\d+\s*ms\b", dod, flags=re.I)
```

**なぜ禁じられているか**: DoD は「完了の定義」であり、**実測値は陳腐化する。** `textual` を入れた瞬間に 804→805 が動いたのが実例である。**DoD に数値を焼き込むと、正しい変更が DoD 違反に見える。**

### 要件

1. **DoD 節から実測値を撤去する。** 「収集床を満たすこと」のような**性質**で書き、**数値は書かない**
2. **記録自体は失うな。** run ID・実測値は `docs/TIER3_DEVICE_VALIDATION_REQUIREMENTS_DRAFT.md` 側か、`AI_SKILLS.md` の **DoD 節以外**へ移せ（そちらに同種の契約は無い）
3. **`python3 -m pytest tests/ -q` が `804 passed, 2 skipped`（開発機）へ戻ること**を確認せよ

> **注意**: 契約テストを緩めて通すな。**テストが正しく、記述が誤っている。**

### 事実

`絶対孤立` ジョブの検査は現在これだけである:

```

```

**skip は一切見ていない。** つまり **3 ファイルのいずれかが skip に転じても、ジョブは緑のまま通る。** 収集数は skip されたテストも数えるため、床 22 も落ちない。

**これは §14 最高 severity（release 停止条件）のジョブである。** 起草者の指示書 §4.4 が床と failures しか明示しなかったことが原因であり、**その曖昧さは起草者の責である。** ここで閉じる。

1. `絶対孤立` ジョブに **skip 列挙**（`-rs`）と **未知 skip での失敗**を追加する
2. **このジョブに許容 skip は存在しない。** 22 件はプラットフォーム非依存の AST / 境界検査であり、**skip が 1 件でもあれば落とせ**
3. desktop suite 側と**同じ実装を再利用せず**、意図を明示せよ —— 許容リストが**空である**ことがこのジョブの仕様である

### 変異ドリル（必須・4 点セット）

1. 3 ファイルのいずれか 1 件に `pytest.skip` を注入 → **ジョブが赤になる生ログ**
2. 復元
3. **緑に戻る生ログ**
4. 併せて **床が落とすこと**（例: 1 ファイル削除で collected < 22 → 赤）も示せ

## F-4 — `NOT MEASURED` を条件出力にせよ

### 事実

現在の実装（`pytest-ci-gate.yml` 165 行目付近）:

```bash
echo "NOT MEASURED: Windows AppContainer pipe contract — ..."
```

**無条件に出力している。** Windows skip が実際に発生したかを確認していない。

**なぜ問題か**: 仮にその skip が消えても（誰かが macOS で走るよう直した等）、ログは「測っていない」と主張し続ける。**検証せずに断定する log 行**であり、**このゲートが防ごうとしているものと同じ型である。**

> 起草者は本プロジェクトで `leaked=0` を 2 度、空虚なまま証拠として報告した。**「測っていない」という主張もまた、測って裏を取るべき主張である。**

### 要件

1. **Windows skip が実際に検出されたときだけ** `NOT MEASURED` を出力する
2. **検出されなかった場合**は、その事実を出力する（例: 期待していた skip が無い ＝ 状況が変わった、と分かる文言）
3. **どちらの分岐でも、ログを読んだ人間が「何を測って、何を測っていないか」を一意に読めること**
